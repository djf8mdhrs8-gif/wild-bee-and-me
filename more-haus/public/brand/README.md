# The logo

Put the MORE HAUS logo here, then point `src/content/brand.ts` at it.

```
more-haus.svg          the logo as supplied
more-haus-ivory.svg    a reversed version, for use over dark photography
```

SVG is preferred. A transparent PNG at 2× works too.

The logo is used as supplied — it is never recoloured, redrawn or restyled by
the site. Until `brand.ts` points at a file, the site falls back to a plain
letterspaced serif wordmark, which makes no attempt to imitate the handwritten
mark.
