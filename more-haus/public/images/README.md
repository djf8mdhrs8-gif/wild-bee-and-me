# Photography

Drop real photographs in here and point at them from `src/content/`.

```
projects/     project photography
collection/   furniture and objects
home-edit/    market days, past and present
about/        portrait, lifestyle, sourcing
journal/      the homepage gallery
```

A file at `public/images/projects/hero.jpg` is referenced as
`/images/projects/hero.jpg`.

Upload the largest version you have — around 2400px on the long edge is plenty.
`next/image` resizes each one and serves AVIF or WebP automatically.

Until a slot has a real photograph it renders a captioned placeholder
describing the shot that belongs there, so layouts are already final.
